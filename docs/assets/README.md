# README assets

- `banner.png`: generated with the built-in image generation tool, using the existing `logo.png` and the Lantern website's autumn poster as references. Final image: 2048 × 683 pixels.
- `download-macos.svg`: local, static vector button. The README supplies the download link and accessible alternative text. It makes no third-party image requests.

## Banner generation prompt

```text
Use case: ads-marketing.
Asset type: finished GitHub README banner, a wide landscape image with approximately 3:1 aspect ratio (2400 x 800 preferred).
Create a beautiful restrained editorial banner for October Lantern, a small native Mac app that tells people when their AI coding agents need a reply.
Input image 1 is the existing Lantern mascot/logo: preserve its recognisable exact orange rounded ribbed lantern body, loop handle and two glossy dark oval eyes. No mouth, arms, legs or redesign. Use this mascot as the large hero on the right, fully inside the frame, glowing softly.
Input image 2 is the existing website's autumn landscape, a mood and palette reference only. Create a related quiet autumn setting: a softly defocused amber woodland/meadow with subtle mountain silhouettes and a deep moss-green charcoal atmosphere. Make the left half dark and calm for extremely legible typography. Rich warm late-afternoon light, understated fine grain, elegant soft falloff, a few softly lit autumn leaves along the lower edge. Premium Mac utility brand, charming but uncluttered, no UI mockup or floating cards.
Composition: left-aligned typography in the left 58%, generous 100px-equivalent margins, fully visible mascot on right 35%, clear separation. At top left small widely spaced warm ivory sans-serif text exactly "OCTOBER". Below it the very large warm ivory refined serif word exactly "Lantern". Below the title, two balanced lines of smaller clean sans-serif text exactly "Know when your AI" and "agents need you." The typography must be accurately spelled and readable at GitHub README width.
No additional text, no buttons, no badges, no claims about open source, no screenshots, no watermarks, no external logos. Fill the full rectangular image edge to edge; no outer device frame or rounded corners.
```
