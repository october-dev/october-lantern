## Implemented

- Merge local cards and Show me; both UI clients render cards, guide state and local routines.
- Stable card-creation IDs, fenced replies/leases and deliberate keyboard focus; no late answer is sent as a new instruction.
- Durable app-access hold, fresh-driver Continue, exact owned-session Stop and graceful driver cleanup on app quit. These are scoped controls, not protected takeover.
- Restored holds close dispatch before card IPC listens, cancel previous waits and recover an orphaned private driver under the ownership lock. Settings Off also recovers an orphan when no hold was saved; shutdown failure is reported as unconfirmed. Recovery requires Cua's shutdown receipt and endpoint release. A live unresponsive child handle is reaped before replacement. PID files and Windows pipe names are scoped to the profile.
- Local schedule editing/confirmation, timezone/DST and occurrence admission, missed-run/overlap/restart handling, one-shot harness execution and inline cards/results. Closed sessions and agent-reported outcomes are distinguished.
- Show me capture/run/round cancellation fences, read-only Cua observation, native Mac ring with an independent renderer expiry, captured-picture mode for portable clients.
- Windows Core runtime discovery and IPC peer-user verification; remove obsolete AI gateway/mode/text-only fallbacks.
- Keychain restoration off the main thread, with generation fencing and a regression test. Standalone forms remain open on outside clicks to preserve input.
- Routine drafts use the computer's IANA timezone (an undetectable zone requires a choice). Scheduling covers every saved routine. Recent-history limits cannot hide live launches or unresolved cards/receipts.
- Both AI clients treat EOF without a terminal `done` receipt as interrupted rather than completed, retaining partial text.
- Both forms share model search/selection. Signed-in October lists its live account catalogue with explicit October routing; failures/expired sign-in show Retry. Request identities reject responses superseded by a refresh/account change. Default follows the harness configuration.
- Unix agent startup uses a 0700 directory and 0600 single-use command file, consumed by a noninteractive shell after login setup. Credentials do not enter the terminal/tmux start arguments; failed dispatch cleans up its file.

The owner explicitly removed protected sign-in/isolation from this beta on 27 October. Scoped Pause/Continue/Stop and ordinary sign-in hand-offs remain in scope, with no promise that arbitrary background commands or observation stopped.
