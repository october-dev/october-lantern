# Video ad

Make a short social media ad the person can post today.

## Ask first

One question card, all at once. Skip anything they already said:
- What it's for (product, business or event) and a link, if there is one
- Logo, photos or clips to use, if any
- Where it goes: Reels/TikTok/Shorts (9:16), feed (1:1 or 4:5), YouTube (16:9)
- Length (default 15 s) and the feel they want

## Make it

- Use Remotion. If its skill isn't installed, run `npx skills add remotion-dev/skills`.
- Work in `~/Movies/Lantern Ads/<short name>/`.
- Before building, show the script and a shot list on a card, and wait for an OK.
- Use a good hook, make the content super genz and viral worthy banger.
- Make it look like a real ad: a hook in the first second, big readable text, safe margins for the platform's buttons, captions for no sound, and a clear call to action at the end.
- Use their logo, colours and pictures when you have them. Otherwise make clean motion graphics. Never invent claims, prices or reviews.
- Add music or a voice-over only if a tool for it is set up, and the person wants one. Keep it royalty-free.
- Render a quick preview first and look at the frames yourself before the final render.

## Finish

Render each size they asked for as MP4 (H.264). End with a result card listing the files. When they ask for changes, edit the same project and render again.
